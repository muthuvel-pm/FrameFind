
# FrameFind

FrameFind is an image-discovery app designed to help users explore visual inspiration by topic. It will eventually let users search for images and view them in a responsive gallery.

I chose a teal-and-orange colour palette to create a calm but energetic visual identity. The category chips make popular search topics easy to discover, while the responsive CSS Grid adapts the gallery to different screen sizes.
